Fonts used to generate participant certificates (app/certificates/generator.ts).
All are licensed under the SIL Open Font License 1.1 (see the *-OFL.txt files) and were
subset to Latin/Turkish characters; variable fonts were instanced at weight 400.

- Kalam-Regular.ttf        participant name   (Indian Type Foundry)
- Arimo-Italic.ttf         Turkish body text  (The Arimo Project Authors)
- Alegreya-Italic.ttf      English body text  (Huerta Tipográfica), digits mapped to lining figures
- CrimsonText-Regular.ttf  serial number      (The Crimson Text Project Authors)
- CrimsonText-Bold.ttf     date
